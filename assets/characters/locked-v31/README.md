# V3.1 锁定人物（透明 SVG 原始母版）

这四张 SVG 与 A151 23 秒技术试片采用相同的角色造型和颜色。SVG 背景透明，可用 CairoSVG / 任何 SVG 编辑器导出透明 RGBA PNG；不应把白底或棋盘格伪装成透明。

**状态：技术测试，不是最终美术定稿。** 特别需要改进坐姿、腿部与家具比例、视角、床单和桌面的遮挡、光照。固定角色 ID 和造型只解决“生图重新生成真人”的漂移问题，不意味着当前样片已符合原视频效果。

- male.svg：同居男性
- female.svg：同居女性
- female_sad.svg：女性独处
- lawyer.svg：曹义德律师的抽象讲解形象（非真实肖像）
