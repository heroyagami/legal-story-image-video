# 法律故事视频交付验收清单

## 0. 真实与授权
- [ ] 核验报道时间、主体、金额、法律规范的适用日期
- [ ] 模拟/综合情节标注“情景演绎”，不冒充真当事人或真实截图
- [ ] 人物素材、背景、音乐、配音具备可用授权；现实案件隐私处理

## 1. 角色
- [ ] 每一角色与统一设定表匹配；律师和故事主角不混淆
- [ ] 角色白圆头、点眼、极简表情，未生成日漫五官、头发或真人纹理
- [ ] PNG 透明通道真实有效（alpha min<255 且 max>0）或 SVG 没有底色
- [ ] 没有边缘毛刺、透视突变、肢体异常、遮挡穿帮

## 2. 场景
- [ ] 背景独立生成且不含人物
- [ ] 透视合理，灯光/阴影方向一致，脚接地
- [ ] 重点段落有暖冷色温变化，画面风格保持统一

## 3. 音频、字幕与剪辑
- [ ] 使用真实旁白时长校准每镜头
- [ ] BGM 不盖过人声，音效落点可靠
- [ ] SRT 文本与声音同步、可读、无明显遮挡
- [ ] 无死帧、跳帧、人物身份漂移、黑场或丢失音轨

## 4. 验收顺序
三张关键静帧 → 20–30秒试片 → 全片剪辑 → 完整观看/听审 → 成片导出与归档。

**验收结果**：`pending` / `passed` / `needs-revision`。未完成观看或听审时只能标记 pending。
