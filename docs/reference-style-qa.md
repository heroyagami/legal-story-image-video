# 视觉参考一致性审片标准

唯一视觉方向：[文字画风宪章](visual-style-bible.md)；源于用户确认的《一个在2019年买到恒大房的普通人会度过怎样的一生呢？》视频及其截图。

**人物**：白色大圆脸、豆豆眼、简化黑/棕发型可见、衣服宽松，二维平面抽象治愈卡通，不是三维白球、无发强制或真人/日漫；跨镜头保持角色衣服、发型、面部比例一致。

**背景**：细腻的现实中国生活空间，可信建筑家具、暖冷光线、景深和空间透视；人物的接触与遮挡自然，坐在沙发、床边照护、律师在桌后都符合常理。

## 强制 FAIL 条件
- 大多数镜头是固定SVG/PNG火柴人被放到写实背景上，人物像贴纸、尺寸不对、遮挡或阴影不自然。
- 真人、3D白球、日式大眼角色或人物跨镜头发型/服装明显漂移。
- 错把“人物不要占满画面”当成将人物硬缩小；人物与沙发、病床、门窗、书桌尺寸不合。
- 九宫格拼贴、信息海报、假的视频播放器截图、大标题条或字幕被烘焙在正式素材内。
- 用程序几何素材代替实际生图，以三张图缩放裁切冒充52张不同生图。
- 没有真正视频却生成“成片预览”概念海报，或者未通过视觉审核即宣称已交付。

## 验收步骤
对照原片视觉特征 → 逐镜生成完整单幅图 → 文字角色卡一致性检查 → 正常人体/家具比例与手部、臀部、衣物遮挡检查 → 逐镜镜头独立性 → 稳镜头60秒试看 → 听审旁白/SRT → 完整版输出。

记录每张真实图像文件、镜头ID、角色ID、审片状态（PASS/FAIL）、失败原因；未通过不得进入正式时间轴。
