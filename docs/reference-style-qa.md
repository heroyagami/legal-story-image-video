# 视觉参考一致性验收｜抽象人物 + 电影写实环境

## 基准
参照用户提供的《一个在2019年买到恒大房的普通人会度过怎样的一生呢？》原视频，而非本仓库早前错误的 A151 动态 PPT 成片。
原参考：人物是白色纯圆头、黑色点眼、无头发的抽象卡通；背景是有真实材质、可信空间、自然光影和景深的中国生活场景。人物与桌椅、门窗、床、车辆发生有因果意义的互动。

## 不可通过的硬性失败项（任一即 FAIL）
1. 背景以矩形、圆形、渐变、程序线条/几何图形模拟房间、医院、法院或城市，缺乏摄影感的真实材质与空间。
2. 场景背景只是其他人像图的整体高斯模糊或低分辨率铺底；主体和场景没有真实透视关系。
3. 人物像贴纸，脚悬空，坐、靠、触摸、陪护等叙事情境中与物体没有接触及遮挡；没有接触阴影。
4. 非片头/片尾镜头出现大号标题栏、进度条、播放器界面、品牌水印、海报拼贴、分镜表或每镜头序号。
5. 人物变为日漫大眼、有头发的 Q 版、带皮肤纹理的真人或每镜头改变头型/服装。
6. 全片大部分时间只有同样的正面站立小人+镜头平移；没有有意义的场景化动作，静态镜头比例失控。
7. 只通过 FFmpeg/程序绘制背景而未实际独立生成写实场景图，却宣称完成“生图视频”。FFmpeg 允许用于剪辑编码，但不可代替关键视觉素材生成。
8. 未经过三张单幅关键帧/短试片的对照审核就直接制作并交付完整版，或者把“合成成功”当作“视觉质量合格”。

## 正确的生产步骤
1. 从真实参考视频选取同类镜头，形成视觉标准（圆头比例、线宽、摄像机角度、背景真实度、接触/遮挡）。
2. 对每一真实叙事空间分别独立生成**无人物、无字、无品牌**的摄影级背景图；场景必须具备家具/墙体/材质/真实光源。
3. 角色制作透明 RGBA PNG；主要角色设正、侧、背和坐/站/扶/低头等姿态，故事主角的衣着跨镜头固定。
4. 设计真实互动：场景角色坐在实体沙发/病床旁，人物与物体使用明确的前后景遮罩，阴影与光色匹配。
5. 镜头变化用摄影逻辑（远景环境 → 中景动作 → 近景情绪/物证）；图生视频尽量只在动作必要时使用，不让场景/人物漂移。
6. 图像之外的画面文字只允许后期添加正常 SRT 字幕及必要法律标注；避免模板式信息牌和浮动 UI。
7. 三张无字实际关键帧 → 对照原片画质验收 → 20–30 秒真实试片（有动作/镜头） → 审核 → 完整成片。

## 验收记录
每期建立 `visual-qa.md`，至少：
- 参照原视频/目标标准：是否有依据
- 实际写实背景源文件：是否真实存在、是否无人物
- 人物 alpha、朝向/动作：是否合格
- 人物与景物互动和光影：是否自然
- 截图对照：同类型三组原片 vs 新片
- 字幕、安全区、音频、法律事实：是否通过
- 失败结论和改进项：必须如实标 FAIL，禁止报“完成”
