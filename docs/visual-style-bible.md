# 画风宪章｜文字定义优先（适用于所有生图与图生视频）
 
本项目唯一有效的画风方向来自用户确认的**原视频《一个在2019年买到恒大房的普通人会度过怎样的一生呢？》**及用户指认“这版最好”的截图。此文档以文字描述画风，**不以 SVG、PNG 抠图、某张角色资产或软件实现固定风格**；参考图只用于观察视觉特征，并不是必须使用的贴图或被复制的素材。

## 1. 人物：极简、治愈、抽象二维卡通
- **白色或接近白色的大圆脸**，黑色豆豆眼，几笔简单眉毛/嘴巴；没有写实鼻子、皮肤、复杂眼睛。
- **可以有头发！** 主角是少量黑色/棕色的块面化短发、刘海或简洁盘发；发型区分角色，绝不要求“全部无发白球”。
- 身体是正常叙事用的**简化二维卡通人体**，四肢、手、衣服可做日常行为；服饰宽松、块面简练、黑色或深色描边。
- 情绪以姿态、轻微表情和环境表现，不做三维塑胶球头、火柴人贴纸，也不做真人摄影人物或大眼日漫。
- 同一角色跨镜头一致：发型、头面比例、衣服形状与主色、身形和关系必须匹配文字角色卡；可改变动作、表情、衣服状态（如住院）。

## 2. 环境：高细节电影感现实生活
- 当代中国的真实生活空间：客厅、厨房、楼道、医院、律所、法院外部、街道等；房屋、家具、灯光、材质、空间深度真实可信。
- 环境可以是写实绘景/高精度电影感插画，不要求真人摄影质感；**人物仍保持抽象二维**，两者反差是原片的美学核心。
- 光照、地面接触、人物在沙发/椅子/床前的遮挡必须自然，人物看起来是场景世界的一部分，不能像硬贴上去的贴纸。

## 3. 构图：比例正常，不是把人物一律缩小
- 以环境建立镜头、中远景为主，视剧情需要穿插少量近景/特写；**不设人物占画面高度百分比限制**。
- 人物与同深度的沙发、病床、书桌、门窗比例正常；留出空间的办法是变更镜头距离/角度/景别，不是将人物简单缩小。
- 人坐在沙发上要压到坐垫，照护者的手要落在被子/病人手上，律师的前臂和椅背/桌面要接触合理。

## 4. 制作方法：整体生成优先，参考图只辅助定妆
- 推荐先写完整**人物文字角色卡 + 分镜场景提示词**，每个镜头**人物与环境一起生成**，或用可控的图像编辑/局部重绘修复互动与一致性。
- 可以使用参考画面帮助一致性，但禁止强制 SVG 插入、程序绘制角色、图层贴纸等已经被用户否决的路线。
- 即使使用图层修复，也必须以**整体画面自然融合**为最终判断标准，不能留下生硬边缘。
- 不能把真人/3D/Q版海报拿来算合格；不能通过缩放三张图计入52张镜头素材。

## 5. 摄影运动
- 默认稳定机位；必要时只做小幅、单向慢推/慢拉；禁止持续摇摆/随机抖动/无理由来回平移。
- 图生视频人物动作应克制自然，保留头型发型服装与场景透视，杜绝角色换脸、衣物漂移和物体穿模。

## 6. 图像审片（任何一项不合格须重做）
1. 人物是否为上述抽象二维卡通，而非真人、球头3D、SVG火柴人或日式动漫？
2. 头型、眼睛、发型、服装是否与该角色文字设定一致？
3. 是否有真实环境、可信尺寸、遮挡/阴影/光照与可读的生活动作？
4. 是否是一张独立 16:9 **无字幕、无标题、无界面** 的单幅镜头，而非九宫格或封面？
5. 不同镜头是否真是不同独立画面？镜头节奏是否沉稳，像人生故事而非动态PPT？
6. 法律案件情景标注为演绎，不能伪造真实判决文书或医院病历。

**判定**：以上全部符合才可标 `VISUAL_PASS`。制作项目的 SVG 历史草稿只保存在 Git 历史中，不是本项目画风的标准答案。
