# A151｜同居伴侣去世，没领证还能分遗产吗？

独立视频项目：`heroyagami/legal-story-image-video`，**与 `vibe-motion-private` 无关**。

## 输入
- 原始配音：MP3，203.4415秒；字幕：85条SRT，至203.28秒。
- 两案来源及法律依据核验：见 [legal-review.md](legal-review.md)。模拟画面不得冒充真实当事人。
- 当前唯一视觉标准：[文字画风宪章](../../docs/visual-style-bible.md) + [人物文字角色卡](../../references/a151-character-bible.md)。

## V4 现行执行
1. [52镜头 scene-plan.json](v3/scene-plan.json) 当前结构版本 V4.1；每个镜头有 `output_image`，保存**一张真正独立的含人物全景**或无人空镜。
2. [52镜头完整生图提示词](v3/image-prompts.md)：二维极简治愈抽象人物（白大圆脸、豆豆眼、**允许简化发型**）与高细节真实生活环境**共同生成**；不用SVG、透明角色贴图。
3. [镜头表 CSV](v3/shot-list.csv)、[质量门槛](v3/QUALITY_GATES.md)：人物和家具尺度正常，稳镜头，禁止九宫格、截图、假播放器。
4. 实际生图后按镜头路径放到单期工程的 `shots/A151-S001.png` 至 `shots/A151-S052.png`，运行 [素材验证程序](../../scripts/validate_shot_assets.py)。程序无法代替画风人工审片。
5. 实际45–60秒试听和抽帧通过后，才能生成整片。片中 MP3/SRT 后期同步，无大字UI。

## 已否决的历史方案
低成本几何背景/动态PPT；三张图裁切长片；不自然的微缩人物；强制无发白球；SVG固定小人贴到背景；九宫格伪视频预览。这些只可在Git历史查阅，不能作为当前生产路线。
