# A151 V3.1｜素材核验及单镜头输出

## 状态（2026-11-06）
此前多次生图测试反复生成九宫格/海报、文字字幕与播放器控件，并非独立镜头；**全部判定不合格**。外部生图路径本轮需要单独授权且未获授权，故未建立新的合格背景资产，不得报告任何已完成52张图片/视频的结果。

## 单图资产入口
52个镜头见 `scene-plan.json`，逐镜提示词见 `image-prompts.md`。
每张背景一张独立文件，按计划放入 `backgrounds/A151-BG001.png` 至 `A151-BG052.png`；不要把九宫格裁成九张来冒充独立生图，也不要将视频播放器截图作为镜头素材。
角色应为独立透明PNG，并按 `docs/perspective-and-framing.md` 与沙发、病床、桌椅和门窗的真实尺度、机位和透视关系匹配。

## 素材进入剪辑前的程序检查

先安装 Pillow，然后执行：

```bash
python -m pip install pillow
python scripts/validate_shot_assets.py \
  --plan episodes/A151/v3/scene-plan.json \
  --asset-root /path/to/A151-assets \
  --report /path/to/A151-assets/readiness.json
```

这一步只检查真实文件存在、尺寸、宽高比及近似重复，**不能自动证明图像美术风格合格**；全量图片还需逐张检查是否多宫格、是否有文字和播放条、人物与场景自然相对尺度、遮挡和接触阴影。未经人工视觉验收，不能标记 video_approved 或“成片完成”。

## 防止再次跑偏
生图任务一次只制作一个场景，不传入整集梗概或“分镜九宫格/海报/视频缩略图”的语义；输出独立场景照片式画面，角色另层合成。外部生成器不能遵守单图条件时，应停止、不计入素材量，并更换可用工具/生成设置，而不是反复试同一种失败请求。


## 新画风修订
此文件为过去的实验状态记录。用户已确定文字描述的二维抽象有简发型人物与电影环境同画面生成路线。无发白球、SVG透明贴图路线均弃用。当前标准参见 `../../../docs/visual-style-bible.md` 和 `../../../references/a151-character-bible.md`，生图仍需实际文件与质量验收。
